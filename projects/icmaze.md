# ICMaze

**EPFL · CS-107 · Two-person project · Java 21 · Maven**

[← All projects](../README.md)

## The project

ICMaze is a maze adventure game. The player explores connected areas, collects keys to unlock portals, manages health and encounters enemies before reaching a final boss.

## Gameplay

- Generated labyrinth areas connected through portals.
- Keys and collectible equipment that support progression.
- Rocks, enemies and interactions with the environment.
- Health management and a final boss encounter.

## Technical scope

The project uses Java and a game engine supplied by the course. Its structure separates the game-specific actors and areas from the underlying engine. Maven manages the Java modules.

It provides experience working within an existing object-oriented framework and connecting player input, game state and interactions between objects.

## Context

I developed ICMaze with a partner in EPFL's introductory programming course, using the game engine and tutorials provided by the teaching team. The coursework code and game assets are kept private.

## Behind the scenes

I got very absorbed in this project, including a final stretch with far too little sleep. The maze was not the only thing I needed to find my way out of. It is a memorable project for me, and a reminder that enthusiasm also needs a sensible stopping point.
