# Ajul

**EPFL · CS-108 · Java · JavaFX**

[← All projects](../README.md)

## The project

Ajul is a digital adaptation of the board game Azul. Players choose tiles, build patterns and score points as the game progresses. The project brings together game rules, state management, a graphical interface and computer players.

## Technical scope

- Representation of tiles, moves, player states and scores.
- Mutable and immutable game-state representations.
- Compact representations of game information.
- A JavaFX interface for the board and player interaction.
- A computer player using Monte Carlo Tree Search.
- Java tests covering game components.

## What makes it interesting

The same game state needs to support rule enforcement, user interaction and automated play. This makes the project a useful example of separating the game model from its interface and reasoning about state changes.
